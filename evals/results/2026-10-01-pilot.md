# Pilot, 1 October 2026

`planted-report` and `clean-report` × arms A, B, C × 1 trial. Run from a session whose working directory's CLAUDE.md describes macro's method, so arm A wasn't fully plain (see "Run it from a clean session" in the eval README).

| Task | Arm | Pass | Recall | Wrong flags | Partly flags | Subagent tokens | Wall time |
|---|---|---|---|---|---|---|---|
| planted-report | A | yes | 7/7 | 6 | 7 | 54,780 | 0.8 min |
| planted-report | B | yes | 7/7 | 8 | 8 | 281,218 | 3.1 min |
| planted-report | C | yes | 7/7 | 6 | 1 | 112,682 | 7.7 min |
| clean-report | A | yes | – | 0 | 8 | 53,505 | 0.6 min |
| clean-report | B | yes | – | 0 | 4 | 277,269 | 3.0 min |
| clean-report | C | yes | – | 0 | 0 | 117,932 | 9.1 min |

The "partly" flags on the clean report are correct claims marked partly, usually because an input such as the baseline method's figures isn't in `data.csv`. They're defensible, but they're noise to a reader.

## What it shows

- **The synthetic report is a ceiling task.** A single plain agent finds all 7 planted errors, so it can't separate the arms. It stays as a regression check.
- **Cost:** B is about 5 times A and C about twice A, for the same result on this task.
- **Rigour:** C was the most careful. It raised no spurious flags on the clean report, cited saved script output throughout, and measured that the planted "95%" Wald interval covers about 88% at n=43. It's one trial, so this is a hint, not a result.
- **Two harness fixes came out of it:**
  - the quote rule (quotes are source text; arithmetic goes in `evidence`);
  - running evals from a clean session.
